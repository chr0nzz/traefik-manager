CrowdSec not configured

Add your LAPI URL plus a bouncer API key, machine credentials, or a mTLS client certificate in Settings → System Monitoring → CrowdSec.

The bouncer key reads active decisions, the machine login reads alerts. They are complementary, not tiered. A client certificate covers both.

No LAPI configured on this agent

The agent reads CrowdSec from its own container environment, not from Traefik Manager. Set CROWDSEC_LAPI_URL on the agent container and recreate it.

The CrowdSec fields on this server in Settings only build the compose snippet below - they are never pushed to a running agent.

With mTLS, the cert paths are resolved inside the agent container, so mount them there too. A client certificate replaces the API key and machine login.
