Remove certificate

Removes this entry from acme.json so Traefik stops renewing it.

Traefik is restarted straight after. It only reads acme.json at startup, so without a restart this change would be undone the next time it saves. A backup of the file is taken first.
If a router still serves one of these domains, Traefik issues a fresh certificate on startup. Let's Encrypt allows 5 identical certificates per week, so repeated removals can lock the domain out until that window clears.
